## 녹화 전 준비
- **브라우저:** Chrome이나 Edge로 https://asura.cafeblanc.kr 을 엽니다. `Ctrl+F5`로 최신 화면을 불러온 뒤 `F11`을 눌러 전체 화면으로 바꿉니다.
- **언어:** 오른쪽 위 🌐 언어 선택에서 **English**를 고릅니다. 심사위원이 영어권입니다.
- **알림 끄기:** Windows 알림을 끕니다(설정 → 시스템 → 알림 → 방해 금지).
- **소리:** 🔊 [Narrator]를 켜 두면 심장 소리와 포효가 함께 녹음됩니다. 녹화 도구에서 마이크는 끕니다.
- **비용:** 녹화 중에는 ⚔️ [Duel]을 누르지 마세요. 누르면 영상 생성 비용(약 $2.08)이 듭니다. 전투 장면은 무료인 🎬 [Free demo battle ▾]로 보여 줍니다.
- **에디터 장면(2:25~2:50):** VS Code나 Kiro에서 `C:\kiroween`을 열어 두고, 터미널도 하나 준비합니다.
- **자막:** 업로드 후 YouTube Studio → 자막 → 파일 업로드 → "타이밍 있음"을 고르고 `docs/demo-subtitles.en.srt`를 올립니다.
- **주의:** 다른 회사 로고, 상표, 저작권 음악이 화면이나 소리에 들어가면 안 됩니다.

- **전체 길이:** 3분을 넘기면 안 됩니다. 2분 50초~2분 55초를 목표로 하세요.
- **나눠서 녹화:** 한 번에 하기 어려우면 장면별로 나눠 녹화하세요. 이어 붙이기는 Windows 기본 앱 **Clipchamp**에서 무료로 할 수 있습니다.

- **자막 시간:** 녹화 후 각 장면이 시작하는 시간이 위 표와 다르면 알려 주세요. `docs/demo-subtitles.en.srt`의 시간을 고쳐 드립니다.
- **업로드 설정:** YouTube에서 공개 범위를 반드시 **공개**로 합니다. "아동용 아님"을 고르고, 제목은 `PROMETHEUS-iPSC — Kiroween 2026 (Frankenstein)`을 권합니다.
